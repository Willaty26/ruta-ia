# AI Earning Path

Crea una plataforma web interactiva y moderna llamada "Ruta IA: Aprende y Gana", diseñada para ayudar a principiantes a familiarizarse con la Inteligencia Artificial y descubrir métodos paso a paso para generar ingresos. El diseño debe ser estilo "Tech SaaS", limpio, profesional, con un modo oscuro elegante (fondo gris muy oscuro, acentos en color morado neón y verde brillante para resaltar los botones de acción).



La página debe estructurarse en una sola página (Single Page Application) con las siguientes secciones dinámicas:



1. HERO SECTION:

- Un título gigante y llamativo: "Domina la IA y Activa tus Fuentes de Ingreso".

- Un subtítulo corto: "Herramientas gratuitas, guías interactivas paso a paso y prompts listos para copiar y usar hoy mismo."

- Un botón principal brillante que diga "Empezar Mi Ruta Gratuita" que haga scroll automático a la sección de herramientas.



2. SECCIÓN 1: "EL PROBADOR DE PROMPTS" (INTERACTIVO)

- Muestra un buscador o un menú desplegable (Dropdown) con opciones de ocupación: "Soy Estudiante", "Soy Emprendedor", "Soy Creador de Contenido", "Busco Trabajo Freelance".

- Al seleccionar una opción, debe renderizar dinámicamente una tarjeta (Card) que muestre un prompt específico de ChatGPT optimizado para esa profesión.

- Cada tarjeta debe incluir un botón funcional de "Copiar Prompt" que copie el texto al portapapeles y muestre una notificación visual de "¡Copiado!".



3. SECCIÓN 2: "RUTAS DE MONETIZACIÓN" (PASO A PASO INTERACTIVO)

- Diseña un sistema de pestañas (Tabs) o tarjetas interactivas para tres modelos de negocio:

  * Ruta A: Creador de Contenido Express (Automatización de videos).

  * Ruta B: Redactor Freelance con IA (Blogs y correos).

  * Ruta C: Micro-Agencia de Páginas Web rápidas.

- Al hacer clic en cada modelo, se debe desplegar un flujo visual paso a paso (Paso 1, Paso 2, Paso 3). Cada paso debe incluir un tip rápido y una recomendación de herramienta.



4. SECCIÓN 3: "DIRECTORIO DE HERRAMIENTAS PREMIUM" (ZONA DE CLICS / AFILIADOS)

- Una cuadrícula (Grid) de tarjetas visuales que filtre herramientas por categoría: "Texto", "Imagen/Video", "Productividad".

- Cada tarjeta de herramienta debe tener: Nombre, un logo simulado, una descripción breve de una línea, y un botón de acción muy llamativo que diga "Probar Gratis ↗" (este espacio simulará los enlaces de afiliados).



5. ESPACIOS PUBLICITARIOS SIMULADOS:

- Reserva de forma elegante dos banners vacíos con bordes punteados que digan "Espacio Publicitario Google AdSense", uno en la barra lateral y otro integrado entre los pasos de monetización, optimizados para generar clics sin romper la estética del sitio.



Asegúrate de que toda la navegación sea fluida, responda de inmediato al hacer clic y sea 100% responsiva para dispositivos móviles.
